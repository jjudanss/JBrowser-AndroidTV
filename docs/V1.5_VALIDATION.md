# JBrowser 1.5.0 validation notes

## Source changes

- `MainActivity` now handles Android WebView file selection through `WebChromeClient.onShowFileChooser` and returns selected document URIs through `onActivityResult`.
- User-initiated `target=_blank` links can open in a new tab; non-user-initiated popup requests remain rejected.
- Playback settings include a persistent allow-autoplay preference, applied when WebViews are created and when the setting changes.
- Browser-managed downloads add the active page's Referer header when it is an HTTP/HTTPS page; cookies and User-Agent remain included.
- `AdBlockEngine` caches cosmetic CSS for up to 24 recent host/setting combinations and invalidates that cache when filter snapshots or per-site cosmetic settings change.
- `AdBlockEngine` recognizes `$badfilter` cancellation signatures and `$all` resource type rules.
- First-/third-party matching now compares best-effort registrable domains using a compact set of common multi-label suffixes.

## Static checks performed in this workspace

- Android XML resources and manifest are parsed as XML.
- GitHub Actions workflow is parsed as YAML.
- Version name, version code, output APK name, release tag and documentation are checked for consistency.
- Java source is inspected for balanced delimiters and the new feature symbols are checked for presence.
- Nine Java smoke checks passed against the filter-rule helper methods: `$badfilter` matching (including option reordering), common multi-label first-party domains, `$all`, and positive/negative resource types.
- The JDK parser successfully parsed all four Java source files without syntax errors.
- The source ZIP is integrity-tested after packaging.

## Checks not performed

- A full Android Gradle build was not run because this workspace does not have the Android SDK or Gradle installed.
- The app has not been installed or exercised on a physical Android TV / Google TV device.
- File picker behavior depends on the TV's installed document picker and may be unavailable on some TV firmware.
- The compact public-suffix table is not the complete Public Suffix List; uncommon domains can be classified incorrectly for first-/third-party rules.
- Video codecs, max resolution, HDR and DRM remain dependent on the TV hardware, Android System WebView and streaming provider.
